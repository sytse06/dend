# D&D Dungeon Master Assistant

A Gradio-based D&D Dungeon Master assistant for playing text adventures with friends.

## Setup

```bash
# Create virtual environment
uv venv
source .venv/bin/activate

# Install dependencies
uv pip install -r requirements.txt

# Run locally
python app.py
```

## Deployment

Deploy to Hugging Face Spaces with the `gradio` SDK.
